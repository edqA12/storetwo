# 暮安智护前端设计规范

更新日期：2026-09-13。适用版本：C:\safe 当前 Gradio 6.20.0 应用。
本文件取代早期 Apple 风格设计草案，以用户确认的“月牙入口 + 侧边栏工作台”方案为准。

## 品牌与色彩

- 名称：暮安智护；定位：老年人跌倒检测平台。
- 主文案：让每一步，都多一份安心。
- 品牌语：以智守护，暮年安然。
- 标识：深蓝拱形小窗中的暖金月牙。页面与侧边栏使用同一 CSS 标识。
- 暮色蓝 #1c3248：入口主标题、主按钮、品牌标识与工作台导航；部分组件沿用 #23394e。
- 暖金 #c8a36a：月牙、细线与导航强调；主入口按钮为暮色蓝。
- 米白 #f8f5ef 与暖白 #fffdfa：页面底色和内容卡片。
- 灰蓝 #426a87：辅助强调；正文辅助色 #5f6f7c。
- 红色保留给告警与停止类操作；不改变算法生成的检测画面及告警语义。

## 入口页

左侧为品牌主文案、平台定位与“进入智护工作台”按钮，右侧为长者居家夕阳插画，底部说明风险观察、事件识别和记录回看。较窄屏幕改为上下排列。
欢迎页背景使用 `linear-gradient(to top right, #f7f4ee 0%, #f8f2e8 35%, #f4e2c9 70%, #ecd0aa 100%)`；页头覆以45%暖白，让暖色从左下向右上增强。渐变仅作用于欢迎页。
插画为品牌装饰，不代表监测结果或真实用户案例。资源随项目本地保存；使用系统字体，不依赖远程 CDN。

## 工作台

原生四个 Gradio 页签分别为视频检测、实时监测、事件中心、前置风险记录。桌面将同一组按钮排列为左侧导航，主区显示标题、操作控件、结果与记录。

桌面侧栏为224px，较窄桌面目标200px；760px及以下通过“功能菜单”展开。“返回首页”保留当前页和组件状态，刷新浏览器按既有规则建立新会话。活动摄像头开启时不能把工作台藏入首页，应先停止摄像头。

## 组件层次与可访问性

- 标题大于说明正文，普通输入字段以16px为主；知识库检索输入和按钮统一44px高，并在标签下水平对齐。助手紧凑快捷栏采用40px高，避免挤占对话区。
- 检测输入、结果、风险分、趋势和记录各自分区，两个评分体系不合并。
- 表格保留内部横向滚动、分页与所有字段；不以缩小字号或删除列适配手机。
- 保留键盘焦点，纵向菜单支持上下方向键、Home/End；菜单支持 Escape 收起。
- 月牙为装饰元素，品牌插画提供替代文本；颜色与文字共同表达状态。
- 原生组件无销毁/重建，原生页签选择继续触发已有历史加载回调。

## 助手与知识库

助手使用暖金月亮入口，满月收起、半月展开；藏蓝、米白配色延续工作台。标题支持拖动，右下角调整尺寸，恢复按钮重置位置和大小，小屏适配视口。标题与输入区固定，聊天内容独立滚动；关闭重复的聊天组件标签。

“解读结果”“总结记录”“知识与引用”共用抽屉容器，但由展示状态选择互斥内容。前两项分别显示各自来源与准备按钮，并共用待发送摘要预览；后一项显示知识库开关、管理、引用与隐私说明。切换入口不自动准备、不发送、不清空对话。摘要确认复选框始终位于输入区。

知识库采用文档管理与检索阅读两栏，1100px及以下上下排列；保留表格内部滚动。输入框标签置于上方，检索按钮与输入本体等高对齐。聊天正文与工具按钮的绘制范围限制在聊天区，不能盖住抽屉。

## 实现与限制

`assets/welcome.html`、`welcome.css` 管理入口；`workspace.html`、`interface.css` 管理工作台；`assistant.css` 管理助手与知识库样式；`navigation.js` 维护导航、窗口尺寸与位置、抽屉视图等展示状态，摘要和检索仍由原生回调处理。

Gradio横向页签有自动溢出菜单。纵向布局通过限定隐藏测量按钮的宽度来保留四个原生菜单；升级Gradio时需回归四菜单、窄屏展开和键盘导航，不修改框架包。

本轮不增加账号、监测对象管理、家属通知、自动救援等未完成业务能力，不改变检测阈值、融合降级、个人基线、历史窗口或CSV导出上限。
