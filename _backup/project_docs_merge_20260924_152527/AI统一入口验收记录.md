# AI统一入口验收记录

> 版本说明（2026-09-13补充）：下列测试属于统一聊天入口实施阶段。当前界面另有“知识与引用”入口，“解读结果”与“总结记录”已拆为不同工具视图；最新交互见 [助手面板优化说明](助手面板优化说明.md)。此补充不是重新运行以下测试。

日期：2026-09-13。目标应用：C:\safe。

## 改动

- 删除前端“日常问答／健康咨询”切换，以统一提问、三个任务快捷按钮和本轮处理标签代替；话题变化不清空成功历史。
- 本地明确规则加 DeepSeek 结构化分类。JSON类别、数量、布尔字段严格校验，不接受额外指令字段。类别只控制固定回答要求与检索范围。
- 普通问题不检索；平台及结果问题查平台资料，健康问题查非平台资料；混合问题允许两类。范围在排序前筛选，启用及审核门槛不变。
- 分类使用去掉摘要附录的最近对话；追问检索只补充近期用户文字，不用助手生成的医学断言作为检索事实。
- 本地紧急规则先于密钥读取、模型分类和检索；分类失败提示重试，取消会传播到异步请求。回答继续使用既有健康边界、摘要确认和安全文本输出。
- 两处清空按钮同步清空历史、摘要确认、引用与处理标签。知识库开关仍明确提示切换会清空对话。

## 验证

- 全套离线测试139项通过（28.70秒），覆盖既有检测、历史分页及助手功能。
- 最后统一原生聊天清空事件后，助手与分类相关40项测试再次通过（6.07秒）。
- 浏览器1440×1000和390×850验证通过：统一入口、健康快捷澄清、症状追问、切换到平台问题、医学词翻译跳过医疗检索、健康引用、无检测结果时拒绝默认零分摘要、紧急规则、清空、拖动、调整大小、移动适配。
- 分类API与生成API使用httpx模拟响应；验证请求结构、隐私裁剪、严格JSON解析、401信息脱敏、超时、截断、空结果和取消。预览不使用真实密钥或个人资料，不发生付费模型调用。
- 依据DeepSeek官方JSON Output文档配置response_format、json提示与输出长度：https://api-docs.deepseek.com/guides/json_mode/。

## 边界

这些结果验证软件流程，不能证明真实模型的意图识别准确率、回答真实性或临床准确率。没有进行临床评估、真实症状数据评估或付费模型质量评测。健康分类可能有误，本地紧急词规则覆盖有限，未触发不代表安全；助手不能确诊或开处方。

本轮不重新下载模型、不重建RAG索引、不更改PDF核对状态、不修改密钥及检测阈值，不包含此前已取消的知识库预览范围界面修改。
