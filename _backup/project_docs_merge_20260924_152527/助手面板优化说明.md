# 助手操作入口

- 解读结果：选择视频检测或实时监测，准备当前结果摘要。
- 总结记录：选择事件中心或前置风险记录，准备选中单条记录摘要。
- 知识与引用：知识库开关、知识库管理、本轮引用原文及数据发送说明。

结果与记录面板共用当前待发送摘要。切换入口不会重新生成摘要，也不会清空对话或草稿；请点击对应的准备按钮，并核对摘要中的来源与内容。准备后仍须手动勾选“本次发送附带已核对的摘要”。

本次只调整界面分组与打开面板的操作，摘要生成、选中记录读取、知识检索与聊天发送逻辑不变。

验证：三个入口独立显示；两个准备按钮的原生回调；未检测及未选记录的提示；准备后未自动勾选发送；知识库管理打开关闭；输入草稿保留；手机端切换、滚动与发送按钮可见。
