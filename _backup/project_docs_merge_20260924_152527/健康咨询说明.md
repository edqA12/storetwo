# 暮安健康咨询

直接在月亮助手输入问题即可；日常问答与健康咨询已统一，不再手动切换模式。助手根据问题及近期对话选择回答方式。普通话题变化和快捷入口切换不会清空对话；切换“使用知识库”开关会清空对话与摘要。

- 可直接输入“我有点头疼”或“吃什么对眼睛好”；“健康问题”按钮会预填咨询开场白，不自动发送。部分明确开场或紧急提示在本地处理，其余发送后可能调用分类和回答接口。
- 症状问题先了解起病、严重程度、伴随症状、外伤、年龄及用药，再给可能原因与就医建议。
- 健康科普直接给一般建议，不提供确诊、处方或自行调药建议。
- 首批本地资料覆盖头痛科普和眼健康饮食，模型也可回答其他一般问题，但会注明资料库未覆盖。
- 在“知识与引用”中展开“本轮参考资料 · 查看引用原文”，可查看本轮提供给模型的资料；回答是否充分对应引用仍需人工判断。资料整理日期为2026-09-09，不代表实时联网搜索，也不代表每句话均已被专业人员审核。
- 明确的部分危险症状可在本地触发急救提示。规则只覆盖有限中文表达，不是经过临床验证的分诊系统；未触发绝不表示安全。紧急情况直接联系当地急救服务。
- 本地紧急提示不会发送本次问题；普通健康问答仍将问题和最近对话发送给DeepSeek。原始视频不发送，密钥配置不变。
