# 暮安智护本地知识库

## 使用入口

打开月亮助手的“知识与引用”，默认勾选“使用知识库”。需要检索的问题会按意图在本地检索已启用且已核对或附来源的片段，再将问题、必要片段交给现有 DeepSeek 接口；普通聊天、翻译等不需要资料的问题可跳过检索。打开“本轮参考资料 · 查看引用原文”可查看提供给模型的实际原文、文件名、页码和版本。引用仅表明资料依据，不证明模型每句话均正确。

当前没有咨询模式切换。切换“使用知识库”复选框会清空当前会话及摘要；仅打开或关闭知识库管理面板、切换助手入口不会清空。紧急症状提示优先于检索及网络请求。检索失败会明确提示，不会冒充已查证；原有检测不依赖知识库。

## 初始资料

- 医疗健康.pdf：5页，19个候选片段。
- 医疗疾病知识库.pdf：6856页，26144个候选片段。
- 现有NHS头痛科普、NEI眼健康饮食摘要和平台说明：共5个可用片段，分别标记“附权威来源”或“已核对平台行为”；不声称完成医学审核。

两份PDF已全部导入并生成向量，但内容仍为“待核对”。可以在管理区试搜，尚不自动参与健康回答。药物推荐、费用、患病/治愈概率、饮食禁忌等字段没有纳入疾病片段。其他字段仍可能有错误；技术清洗不能替代专业审核。

## 管理与核对

1. 点击“知识与引用”→“打开知识库管理”，在“选择要管理或检索的文档”中选择目标文档。打开或刷新目录后默认选中目录首项，请再次核对选择。
2. 在右侧本地检索预览输入问题，点击与输入框等高对齐的“检索预览”按钮。当前预览范围是所选文档，不是全库；若内容不相关，请先切换文档再检索。勾选“包含待审核／停用资料”只影响此处预览，不调用DeepSeek。
3. 点击结果行，查看原文和页码，可下载本地保留的PDF原件。
4. 需要用于回答的片段，应先核实内容，填写核对依据，再勾选确认并点击“允许所选片段参与回答”。这是用户核对状态，并不表示医生认证。
5. 可撤回所选片段，或停用整份文档。新的检索立即使用最新启用状态。

上传PDF、UTF-8 TXT或Markdown即可导入；最大100 MB。扫描PDF需要先OCR，空文本不会被当作成功。大文件建议在停止检测时导入。相同文件重复上传不会增加重复条目；同名文件内容更新会生成新版本、停用旧版本，核对状态不会自动继承。中断后点击“补齐向量索引”可继续未完成部分。

## 实现与边界

- 中文向量：本地 BGE-small-zh-v1.5 的量化ONNX版本，CLS向量归一化；模型及tokenizer文件哈希保存在models/rag/manifest.json。
- 关键词：SQLite FTS5 BM25，中文双字词项与英文/数字词项。
- 混合召回：向量和关键词各取30个候选，倒数排名融合；按主题匹配及词项覆盖重排，限制同主题重复。此版本是规则重排，未使用独立神经交叉编码器。
- 多轮补全：统一入口判断为追问时，检索问题可补入最近最多3条用户问题，并限制长度、排除摘要附录；不使用助手生成的断言作为检索事实。不是完整的自然语言指代解析。
- 片段保留小数和单位，疾病字段跨页合并；超过长度上限的字段分段，每段带主题。页码表示所属完整字段/小节的原始页范围。
- 初步相关性门槛为工程规则，非医学概率。仅做代表性检索测试，不宣称临床准确率，也未证明对所有问题优于其他检索方案。
- 临床审核前不得将待核对内容用作诊断、处方或自动处理告警的依据。

## 数据与部署

原始PDF副本位于 `data/knowledge/originals/`，清洗结果为 `data/knowledge/` 下的 `.cleaned.jsonl` 文件，索引为 `data/knowledge/knowledge.sqlite3`；PDF未被JSON替代，原件与清洗片段并存。模型在models/rag；新增依赖独立存放于vendor/rag，不替换YOLO或PyTorch。
运行时不访问模型下载站点。建库和检索不上传PDF；启用知识库发送问题时会将必要的原文片段交给DeepSeek。密钥仍由ai_config.yaml/环境变量读取。

本地命令可执行：`.venv\Scripts\python.exe scripts\import_knowledge.py 文件路径`。不提供路径则只补齐缺失向量。

依赖重装：`.venv\Scripts\python.exe -m pip install --target vendor/rag --no-deps -r requirements-rag.txt`；运行仍依赖原项目已安装的NumPy等基础库。离线迁移需带上models/rag和vendor/rag，或重新获取对应模型。不要将含密钥的配置、私有健康文档和个人数据库分享出去。

模型来源：https://huggingface.co/BAAI/bge-small-zh-v1.5 （MIT）
ONNX转换版本：https://huggingface.co/Xenova/bge-small-zh-v1.5
