# 真实近跌倒逐事件标注协议

## 1. 适用范围

本协议用于 `real_pre_fall_event_annotations.csv` 中 `NEAR_FALL` 事件的时间边界标注。数据集提供的活动类别与本项目补充的时间边界分开记录，避免把人工边界误表述为官方逐帧真值。

## 2. 事件定义

近跌倒是未发生身体着地、但出现可见的非计划性失衡，并通过跨步、屈膝、躯干调整、摆臂或借助支撑恢复稳定的事件。

- `start_s`：首个可稳定辨认的失衡或纠正反应帧。
- `end_s`：人体重新取得稳定支撑并恢复原活动的首帧。
- 单纯快走、转身、主动弯腰、主动坐下、主动跳跃均不标为近跌倒。
- 若最终出现身体着地，则按跌倒事件处理，不同时标为近跌倒。

## 3. 标注流程

1. 第一遍以 0.10 秒间隔浏览整段视频，定位候选区间。
2. 第二遍按原始帧率逐帧复核候选区间的开始和结束。
3. 记录视频帧率、事件起止秒数、活动类别来源、边界标注方法和备注。
4. 同一数据源至少加入正常步态和外观相近的剧烈动作负样本，检查误报。
5. 修改边界后必须重新运行逐事件评测，不手工改写预测或指标文件。

## 4. 当前标注

SisFall D18 `Stumble while walking` 的近跌倒事件标为 10.050–10.800 秒。开始点是首次可见的突发屈膝/失衡纠正动作，结束点是重新恢复稳定步态。原视频约 29.97 FPS，因此边界精度不应解读为高于一帧（约 0.033 秒）。

## 5. 证据等级与限制

- 活动类别：SisFall 官方 D18 定义。
- 时间边界：本项目单标注者两遍复核，状态为 `manual_frame_verified`。
- 当前结果可形成可复算的工程验收指标，但只有 1 个近跌倒正事件，不能作为临床性能或普适性能结论；后续应增加多主体、多视角正事件并进行双人独立标注与争议裁决。
