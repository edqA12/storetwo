# 专项场景与跌倒事件标注协议

## 1. 数据范围

`specialized_scene_clips.csv` 汇总本地可复算的真实人体专项视频，包括模拟跌倒、深蹲/弯腰等困难负样本、坐下/起身、慢走、快走、近跌倒和跳跃。`specialized_event_annotations.csv` 保存 FALL、NEAR_FALL、SIT_DOWN 和 SIT_TO_STAND 的逐事件区间。

数据集官方类别、官方逐帧标签和本项目人工场景描述分列保存。人工描述不替代或冒充数据集官方标注。

## 2. URFD 跌倒时间边界

URFD 官方 `urfall-cam0-falls.csv` 逐帧标签定义为：

- `-1`：人体尚未躺地；
- `0`：跌倒过渡过程；
- `1`：人体已躺在地面。

本地6段 RGB 视频均为30 FPS，且帧数逐段与官方相应序列完全一致。官方帧号从1开始，本地视频时间从0开始，因此换算公式为：

`timestamp_s = (official_frame_number - 1) / 30`

每个 FALL 事件的 `start_s` 取第一次出现标签 `0` 的帧，`end_s` 取第一次出现标签 `1` 的帧。这样得到的是“官方跌倒过渡区间”，不是人工选择的告警窗口。

## 3. 其他事件与场景

- CAUCAFall 坐下/起身时间段来自 OmniFall 统一标签。
- SisFall D18 的近跌倒类别来自官方活动定义，起止时间按 `real_pre_fall_annotation_protocol.md` 逐帧复核。
- URFD ADL 的 `NON_FALL` 类别来自官方数据集；具体“弯腰、深蹲、取物”等场景描述由本项目查看视频后补充，状态为 `manual_scene_review`。
- 没有目标事件的视频不添加空事件或伪造时间段，而是通过视频清单进入该事件类型的负样本集合。

## 4. 评测规则

所有事件采用一对一时间段匹配。预测发出时刻落在真值区间前0.5秒至区间后0.5秒内即为匹配；一个预测最多匹配一个真值事件。输出事件级 TP、FP、FN、Precision、Recall、F1、检测延迟和视频级混淆矩阵。

这些结果属于受控模拟数据上的工程验收，不代表自然发生的老年人跌倒或临床性能。不得要求老年人模拟跌倒；自行扩充数据时，应由健康成年人在专业防护和知情同意下完成。
