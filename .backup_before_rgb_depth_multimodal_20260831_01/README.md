# 暮安智护：视觉跌倒检测系统 MVP

这是“暮安智护——多模态AI老年人跌倒风险预警系统”的初代视觉原型，先完成以下闭环：

- 上传视频并生成带人体骨架、风险值和状态的检测结果视频；
- 使用浏览器摄像头进行连续姿态检测；
- 依据“快速下降或旋转 → 持续横卧”的时序证据判断跌倒；
- 保存告警时间、风险值、触发原因和截图；
- 在事件中心确认告警、标记误报、导出CSV；
- 为后续增加其他感知模态保留独立感知分支和事件融合接口。

> 重要：本项目是学生科研和演示原型，不属于医疗器械，不能替代照护人员判断、临床诊断或紧急救援。不得让老年人模拟跌倒。

## 1. 快速开始

### 第一次运行

1. 确认电脑安装了Python 3.10～3.13，推荐3.11或3.12。
2. 双击 `setup.bat`。
3. 脚本会创建独立的 `.venv` 环境、安装依赖、下载轻量姿态模型并运行测试。

本机第一次安装需要下载PyTorch、Ultralytics和模型文件，耗时取决于网络速度。

### 日常启动

双击 `start.bat`。浏览器会自动打开：

    http://127.0.0.1:7860

系统只监听本机地址，不会自动把摄像头或视频发布到互联网。

## 2. 使用方法

### 视频检测

1. 打开“视频检测”页签。
2. 上传MP4、AVI、MOV等常见视频。
3. 选择人体检测置信度和处理速度。
4. 点击“开始检测”。
5. 查看结果视频、最高风险、风险曲线和本次事件。
6. 下载标注后的视频。

默认限制：单个视频不超过300MB、时长不超过10分钟。这些值可在 `config.yaml` 修改。

### 实时监测

1. 打开“实时监测”页签。
2. 允许浏览器使用摄像头。
3. 让人物全身进入画面，并尽量固定摄像机。
4. 页面会显示人体骨架、当前状态、风险值和处理帧率。
5. 跌倒条件成立时，画面显示红色告警并尝试播放提示音。
6. 可点击“我没事（标记误报）”或“确认告警”。

摄像头重新启动前建议点击“重置监测状态”。浏览器停止摄像头或清空输入时，系统也会重置会话状态。

### 事件中心

- 点击“刷新记录”读取最新告警；
- 点击表格中的事件查看截图和详情；
- 将事件标记为已确认、误报或已处理；
- 导出UTF-8编码的CSV记录。

## 3. 检测原理

系统没有把YOLO单帧输出直接当作“跌倒”。流程如下：

    视频或摄像头
        ↓
    YOLO Pose人体框与17个骨架关键点
        ↓
    会话内轻量人体跟踪
        ↓
    躯干角、中心下降速度、旋转速度、运动幅度、横卧分数
        ↓
    时序状态机
        ↓
    正常 / 快速下降 / 疑似跌倒 / 已跌倒 / 躺卧异常

红色跌倒告警需要观察到：

1. 人体中心快速下降，或躯干在短时间内快速旋转；
2. 随后身体持续接近水平；
3. 横卧状态达到规定持续时间。

静止只会增加风险分，不是必需条件，因为跌倒后的人可能继续挣扎。若没有捕捉到快速下降证据，但人物持续横卧达到3秒且姿态质量足够，系统会记录黄色“疑似跌倒”二级事件；只有完整证据链才触发红色跌倒告警。

## 4. 默认阈值

阈值均位于 `config.yaml`：

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `confidence` | 0.30 | 人体框最低置信度 |
| `keypoint_confidence` | 0.25 | 关键点最低置信度 |
| `lying_enter_angle_deg` | 60° | 进入横卧判断的躯干角 |
| `lying_exit_angle_deg` | 40° | 退出横卧判断的躯干角 |
| `fast_down_velocity` | 0.20/s | 归一化人体中心下降速度阈值 |
| `fast_angle_velocity` | 48°/s | 躯干快速旋转阈值 |
| `lying_hold_s` | 0.6秒 | 有下降证据时的横卧确认时间 |
| `unexplained_lying_s` | 2秒 | 无下降证据时黄色提示时间 |
| `suspected_fall_hold_s` | 3秒 | 持续横卧二级事件确认时间 |
| `event_cooldown_s` | 9秒 | 同一人员重复告警冷却时间 |

这些只是MVP初始值，不代表临床阈值。正式实验应按受试者独立测试集、机位和场景调整，并报告混淆矩阵、跌倒召回率、精确率、F1、误报次数和告警延迟。

## 6. 运行测试

在项目目录运行：

    .venv\Scripts\python.exe -m pytest

检查环境：

    .venv\Scripts\python.exe scripts\check_environment.py

默认自动化测试不会联网，也不会调用真实YOLO权重，便于快速回归。

## 7. 性能优化

本项目默认按无NVIDIA显卡的CPU电脑配置：

- 使用轻量 `yolo11n-pose.pt`；
- 输入尺寸512；
- 摄像头约每0.2秒提交一次最新画面；
- 模型推理全局串行，避免CPU内存耗尽；
- 视频可选择每2帧或3帧推理一次；
- 会话状态相互隔离，不共享跟踪历史。

如果摄像头很卡：

1. 把 `image_size` 从512调到416；
2. 提高人体检测置信度；
3. 降低浏览器摄像头分辨率；
4. 后续可将模型导出为ONNX/OpenVINO，利用Intel硬件加速。

## 8. 已知边界

- 这是单摄像机、单房间、以单人为主的MVP，多人交叉时ID可能切换；
- 半身出画、严重遮挡、黑暗、镜头晃动会降低可靠性；
- 摄像机俯视角、床面高度和拍摄距离改变后需要重新验证阈值；
- 正常快速躺床、地面锻炼和快速坐地是重要误报场景；
- 浏览器可能阻止自动播放告警声音，因此视觉告警为主；
- 视频输出默认去除音轨，以保护隐私并简化浏览器兼容性；
- 当前检测的是跌倒事件和姿态异常，还不等同于长期跌倒风险预测。

建议至少测试：站立、正常行走、坐下、蹲下、弯腰、慢慢躺床、快速坐地、地面锻炼、跌倒后起身、跌倒后静止、半身出画、遮挡、黑暗和多人交叉。

## 9. 隐私与安全

- 所有推理和数据库默认在本机运行；
- 不要使用真实老人隐私视频进行公开展示；
- 数据采集前取得知情同意，并定义保存期限与删除机制；
- 告警截图和事件数据库位于 `data` 目录，转交电脑前应人工清理；
- 模拟跌倒只能由健康成年人在体操垫、护具和观察员保护下完成；
- 原型不能自动拨打真实急救电话。
